      Explore settings

      Check contrast against

      Each colour is fully opaque and must reach 4.5:1 against the backdrop. That is the AA minimum for text in both WCAG 2.1 and 2.2 (success criterion 1.4.3), and it also clears the 3:1 needed for icons and control edges.

      Off by default. When on, the colour you see is sent as a hex code to the Color Name API (api.color.pizza), which matches it against about 32,000 names. Like any web request, this also shares your IP address with that service. Nothing else is sent. When off, or when the lookup fails, Dathanna uses a built-in list of CSS colour names.

      Changes apply to the next colour you see.

      Vetoed colours

      Show or hide vetoed colours

      A veto belongs to the backdrop it was made on. That colour, and any that look almost the same on that backdrop, will not come back there. It can still appear on the other backdrop.

        About Dathanna

        Dathanna is a small colour explorer by Nuadyr. It picks fully opaque red, green and blue values at random using your browser’s secure random source, keeps only the ones that pass AA contrast, and names each with its closest CSS colour name. Online lookup of richer names is optional and off by default.

        Prefer not to swipe? Every card has Keep and Veto buttons, and the left and right arrow keys work too. Your library and vetoes are saved only in this browser. The only thing that leaves it is the hex code of a colour being named, and only while online names are on.

        Colours are filed under the backdrop they were kept on. A colour kept on white can still be offered again on black, and the other way round. Select a colour to see its details.

        Type a colour name (rough spelling is fine) or a hex code. Your search becomes a hex code, and the 30 nearest kept colours are shown on white and again on black. Every kept colour is checked on both, wherever you kept it. Clear the box to see the whole library again.

            Theme Builder

            Select a CSS variable above the preview, or tap a part of the preview, then pick a colour for it from your library. Every variable except the page background also has an opacity slider in the picker. Checks use WCAG AA, and a translucent colour is checked as it looks over the page or card behind it. Disabled controls are exempt from contrast rules, so only placeholder and struck-through text are checked.

              Elements in the preview

              The preview uses real header, nav, search, section, article, aside, address, blockquote, figure, figcaption, details, summary, dialog, ul, ol, menu, li, dl, dt, dd, table, caption, colgroup, col, thead, tbody, tfoot, tr, th, td, fieldset, legend, label, input, textarea, select, optgroup, option, datalist, button, meter, progress, output, hr, img, canvas and footer elements, plus status messages, a focus ring, a visited link, inline text (strong, em, mark, code, kbd, samp, var, abbr, time, sub, sup, ins, del, s, q, small, pre), nested lists, breadcrumb and pagination navigation, and password, number, date and file inputs with invalid and disabled states. The preview frame stands in for body, and a plain div stands in for main, because this page already has its own main. A datalist has no box of its own and its suggestions are drawn by the browser, so the preview includes the input that uses it but cannot show or theme the list. The look of an open select and of the selected option in a list box is partly up to the browser. The picture and the chart are redrawn in your theme colours.
